# **第一章 序言**

## **公正是构建理想国家的基础**

人类建立公正国家的尝试由来已久。历史上几乎所有的社会经济制度都试图贯彻**公正的原则**：每个人的劳动都应得到充分的回报，每个人的优点都应得到公平的承认，每个人都应根据自己的能力和优点在社会中占据公平的地位。

然而，在**奴隶制、封建主义或资本主义**等剥削性社会经济形态中，正义原则并不总是起作用。更常见的情况是“强者的权利”在起作用：属于统治阶级的人占有物质财富的绝大部分，而属于被剥削阶级的人只能得到其劳动力再生产所需的最低限度的东西。

**真正公平的物质财富分配在任何剥削性制度下都不可能实现。**在一个**生产资料私有制**占主导地位的社会里，公正是不可能实现的。因为谁拥有生产资料，谁就能获得更多的有利地位。仅仅因为拥有生产资料，拥有者就能获利，而没有生产资料的人则被迫出卖劳动力，为了生存而出卖自己的劳动力。

私有财产拥有者的资本总是比任何劳动者的工资增长得快。随着资本的增长，他影响重要社会决策的能力也会增长，对他人的权力也随之增长。他的意见也比其他人更受重视，仅凭**私人生产资料所有权**这一事实，就能主宰社会。在这种情况下，**社会公正和社会正义就无从谈起**。

没有公平的物质财富分配机制，就不可能建立一个公平的国家。而在生产资料私有制占主导地位的情况下，这样的分配机制是不可能实现的。**只有当生产资料公有，公平分配才能成为可能。**

曾有人尝试在国家范围内建立**计划经济**，尤其是苏联。然而这一尝试并不完全成功，这被**西方自由主义宣传**所利用，形成一种固有看法：计划经济不如市场经济，既不能带来增长，也不能保障质量，更无法实现财富的公平分配。

在某种程度上，这些批评有其合理性。但我们应当认识到，计划经济是一种**依赖高技术的信息密集型经济体制**，需要庞大的经济信息处理能力、强大的计算能力、现代通讯手段与先进的信息技术支持。

在苏联时期，这些技术条件尚未成熟。作为社会经济实践，苏联的计划经济**大大超前于其时代**。科学与技术的发展速度远远落后于其社会制度的进取性。

直到今天，苏联解体近三十年后，**信息技术的飞跃式发展**终于让高效的计划经济成为技术上可能。我们现在拥有了所需的计算能力、通信手段和软件系统。

因此，**在生产资料公有制的基础上，借助现代信息技术的计划经济**，实现公平国家的建设迎来了**新的历史机遇**。

这种新型计划经济，不仅比苏联时期更高效，也有潜力超越现行的市场经济体系。**只有这样，才能建立一个真正公平、强大和繁荣的国家。**
